\begin{frame}{Why This Update}
\begin{itemize}
  \setlength{\itemsep}{10pt}
  \item INFORMS Annual Meeting (July 2026) presented a flagship result: 483 text signals
        predict future patient-harm risk in facilities where FDA's own classification (VAI)
        carries the least information.
  \item That analysis used an earlier extraction (before Claude Sonnet 5 was pinned as the
        validated model, and before the round-1 human-label validation and prompt fixes
        documented in the LLM Extraction Validation Report).
  \item \highlight{This deck reruns the exact same test on the current, validated data} --
        same panel construction, same cohort definition, same models -- to see whether the
        claim holds up.
\end{itemize}
\end{frame}

% ─────────────────────────────────────────────────────────────────────────────
\begin{frame}{Study Design (unchanged from INFORMS)}
\begin{itemize}
  \setlength{\itemsep}{8pt}
  \item \textbf{Unit:} one inspection event
  \item \textbf{Features:} 17 LLM text signals from the 483 (now from the validated v2 prompt,
        Claude Sonnet 5)
  \item \textbf{Outcome:} above-median adverse events in the 4 quarters after inspection
  \item \textbf{CV:} FEI-grouped 5-fold logistic regression and random forest
  \item \textbf{Cohort:} inspections with an ANDA-matched FAERS record in the outcome window --
        \highlight{176 inspections, 78 FEIs} (98 FEIs, 33 OAI, before this filter)
  \item \textbf{VAI-only subgroup:} 55 facilities that never received an OAI in this panel --
        \highlight{110 inspections}
\end{itemize}
\vspace{6pt}
{\small Cohort sizes above match the original INFORMS slide exactly -- confirms this rerun is a
faithful replication of the original setup, not a different test.}
\end{frame}

% ─────────────────────────────────────────────────────────────────────────────
\begin{frame}{Why the Numbers Moved}
\begin{itemize}
  \setlength{\itemsep}{10pt}
  \item The text features themselves changed twice: first, the current extraction is
        human-validated (independent blind review, 68--96\% field accuracy) with two real prompt
        bugs and several rule gaps fixed after the INFORMS numbers were produced. Second, a
        severity-feature bug fix landed the same day this rerun was first drafted:
        severity\_tier's real confusion is at the Major/Moderate boundary, not Critical/Major, so
        severity\_majmod\_share replaced severity\_critmajor\_share as the severity feature
        everywhere, moving the VAI-only numbers again (RF: p=0.032 $\to$ p=0.080).
  \item This is not a case of ``the old number was wrong, ignore it'' -- it is the expected
        result of tightening the pipeline twice in the same direction. A weaker, no-longer-
        significant effect on more rigorously validated data is a more honest basis to build on
        than a stronger effect on data known to have had extraction bugs at the time.
  \item Sample size remains the binding constraint either way: 55 VAI-only facilities, 110
        inspections. INFORMS's own slide called this subgroup result ``hypothesis-generating,''
        and that framing applies at least as much now.
\end{itemize}
\end{frame}

\section{Part 2: Extending to Shortage}

\begin{frame}{Part 2: Extending to Shortage (m19)}
\begin{itemize}
  \setlength{\itemsep}{10pt}
  \item Part 1 asked whether 483 text predicts \emph{adverse events} in VAI-only facilities.
        The project's actual motivating hypothesis is about \emph{shortage}: if VAI does not
        force the same remediation OAI does, an undetected quality problem at a VAI facility
        could keep degrading and eventually cause a shortage.
  \item m19\_shortage\_fei\_model.py tests this directly for the first time this session,
        using a facility-year panel (not inspection-event) and the FDA Inspection Details file
        as the primary OAI/VAI source.
  \item Three models, same significance-testing convention as Part 1 (one-tailed $t$-test of
        fold-level AUCs vs.\ 0.5).
\end{itemize}
\end{frame}

% ─────────────────────────────────────────────────────────────────────────────
\begin{frame}{Study Design: Facility-Year Shortage Panel}
\begin{itemize}
  \setlength{\itemsep}{8pt}
  \item \textbf{Unit:} one facility (FEI) x year, 2015--2024
  \item \textbf{Outcome:} does any drug this facility manufactures enter a University of
        Utah-tracked shortage in year $t{+}1$
  \item \textbf{Universe:} 127 FEIs (our full reference universe with FDA Inspection Details
        records, not restricted to 483-text coverage -- same universe fix applied to m14/m17)
  \item \textbf{Three models, checked independently:} baseline (inspection + structural
        features, all 127 facilities), with-text (full feature set, text-covered subset only),
        VAI-only subgroup (text features, facilities with no OAI on record as of year $t$)
\end{itemize}
\vspace{8pt}
\begin{alertblock}{Limitation, kept explicit}
\small Shortage exposure is bridged from drug-level UUtah events through the Valisure
FEI-API map: every facility manufacturing a shortaged drug is marked ``exposed,'' whether or
not that facility caused it. Same reason the team moved off shortage as the primary outcome
in June 2026 -- m19 tests the VAI hypothesis specifically, not a reversal of that decision.
\end{alertblock}
\end{frame}

% ─────────────────────────────────────────────────────────────────────────────
\begin{frame}{Where This Points Next}
\begin{itemize}
  \setlength{\itemsep}{9pt}
  \item \textbf{More data, not a different model.} The VAI-only cohort is still small (55
        facilities for AE, 28 shortage events) because 483-text coverage is still short for
        many facilities. Sample size, not signal quality, is what keeps the
        logistic-regression versions from clearing significance in both parts.
  \item \textbf{Resolve the LR/RF disagreement.} The VAI-only shortage result is significant
        under Random Forest but not logistic regression -- worth understanding whether that's
        a real nonlinear pattern RF is finding, or an artifact of the small sample, before
        leaning on it.
  \item \textbf{Done: OAI/VAI source aligned across both parts.} Part 1's analysis now matches
        m19's source order (FDA Inspection Details primary, Redica fallback). Rerunning
        reproduced the identical cohort and identical AUCs -- a useful robustness check.
  \item \textbf{The baseline finding needs the same scrutiny Part 1 got.} Significance-tested,
        but not yet stress-tested across repeated reruns and cohort checks the way the
        VAI-only AE comparison has been over several sessions.
\end{itemize}
\end{frame}
